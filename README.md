# GitHub Training Demos

Welcome to the **GitHub Training Demos** repository.

This repository contains practical demonstrations used in GitHub training sessions delivered by **Ricardo Cabral**. Each folder represents a different scenario, feature, or use case designed to help trainees/participants understand and gain hands-on experience with GitHub.

## Purpose

The goal of this repository is to provide examples and demonstrations of:

- GitHub Repositories
- GitHub Pages
- GitHub Actions
- Workflows and Jobs
- Artifacts
- Environments
- Secrets and Variables
- Pull Requests
- Branching Strategies
- Reusable Workflows
- Docker Integration
- CI/CD Concepts
- GitHub Projects
- and more...

## Repository Structure

Each directory contains an independent demonstration.
